Export & Publish

📤 Export data.js

Your website is fully static. Content created here lives in your browser's localStorage. To make it permanently public, export and commit the data file to GitHub.

  1. Click Export data.js below
  2. Replace js/data.js in your project with the downloaded file
  3. Commit & push to GitHub — your site updates automatically
💡 Tip After committing the file, new visitors will see your posts immediately. The blog and portfolio pages always load from both the committed file and localStorage.
